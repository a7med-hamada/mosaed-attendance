# 🏢 منظومة إدارة حضور وانصراف قوى العمل المتطورة
### Workforce Attendance & HR Management System

نظام ويب متكامل واحترافي لإدارة حضور وانصراف الموظفين، التحقق الجغرافي الدقيق (GPS Geofencing)، وإثبات الحضور بالصورة الحية (Facial Photo Evidence)، مع لوحة تحكم ذكية وشاملة للمدراء.

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. تجربة الموظف الذكية (Employee Mobile-First Experience)
- **واجهة تسجيل حضور مبسطة وسريعة:** تدعم الهواتف المحمولة وشاشات سطح المكتب.
- **ساعة رقمية حية:** وتاريخ اليوم بالتقويم العربي.
- **التحقق الجغرافي الفوري (GPS Verification):**
  - فحص المسافة بين الموظف ومقر العمل بالاعتماد على معادلة **Haversine**.
  - منع تسجيل الحضور في حال كان الموظف خارج النطاق المسموح به (مثلاً أكثر من 150 متر) مع إظهار المسافة الحالية ورسالة واضحة: *"لا يمكنك تسجيل الحضور لأنك خارج نطاق موقع العمل"*.
  - فحص دقة الـ GPS وتنبيه الموظف في حال كانت الإشارة ضعيفة.
- **إثبات الحضور بالصورة الحية (Camera Selfie Verification):**
  - فتح كاميرا الجهاز مباشرة والتقاط صورة شخصية حية (WebRTC Stream).
  - معاينة الصورة وإمكانية إعادة الالتقاط قبل الاعتماد.
  - حفظ الصورة وتاريخ ووقت التسجيل وإحداثيات الموقع ومعلومات المتصفح وIP الموظف.
- **تسجيل الانصراف:**
  - توثيق وقت الانصراف بدقة وحساب إجمالي ساعات العمل تلقائياً.
  - إمكانية إلزام الموظف بالتقاط صورة عند الانصراف حسب إعدادات الإدارة.
- **سجل الحضور الشخصي:** عرض كافة أيام الحضور السابقة، الصور الموثقة، والتأخيرات.
- **الملخص الشهري والخصومات:** إحصائيات فورية لأيام الحضور، التأخيرات، الغياب، ساعات العمل، والخصومات التقديرية.
- **طلبات تصحيح الحضور (Correction Requests):** إمكانية تقديم طلب رسمي للمدير لتعديل الحضور في حال نسيان التسجيل أو حدوث مشكلة تقنية، ومتابعة حالة الطلب (قيد المراجعة / معتمد / مرفوض).

---

### 2. لوحة تحكم وإدارة المنظومة (Manager / Admin Portal)
- **لوحة متابعة حية وفورية (Real-time Live Attendance Dashboard):**
  - 8 بطاقات إحصائية رئيسية: إجمالي الموظفين، الحاضرون، في الموعد، المتأخرون، نصف يوم، الغائبون، على رأس العمل الآن، تم الانصراف، ونسبة الانضباط.
  - جدول حي لحظي يتحدث تلقائياً (Auto-Refresh) مع إمكانية التحديث اليدوي.
  - فحص إثبات الحضور: نافذة تعرض الصورة الشخصية وخريطة تفاعلية توضح المسافة وموقع الموظف بالنسبة لمقر الشركة.
- **التعديل اليدوي الموثق (Manual Attendance Override):**
  - إمكانية قيام المدير بتعديل وقت الحضور أو الانصراف أو الحالة مع **اشتراط كتابة مبرر التعديل** وتوثيقه آلياً في سجل الرقابة (Audit Log).
- **إدارة طلبات التصحيح:** مراجعة طلبات الموظفين، الموافقة عليها (مع تحديث السجل آلياً) أو رفضها مع كتابة الملاحظات.
- **التقارير الشاملة وتصدير البيانات:**
  - تقرير شهري تفصيلي لكل موظف.
  - تصفية متقدمة حسب القسم، الموظف، التاريخ، والحالة.
  - **تصدير فوري إلى Excel / CSV** يدعم اللغة العربية بدون تشويه بفضل UTF-8 BOM.
  - ميزة الطباعة الرسمية للتقارير (Print View).
- **إعدادات موقع العمل والنطاق الجغرافي (Workplace & Geofence Map Settings):**
  - خريطة تفاعلية (Leaflet.js) تمكن المدير من النقر لتحديد موقع الشركة أو سحب العلامة.
  - زر *"استخدام موقعي الحالي"* لضبط إحداثيات المقر عبر الـ GPS.
  - شريط تمرير لتحديد نصف القطر المسموح به (مثلاً 50 إلى 1000 متر) مع رسم دائرة مرئية على الخريطة.
- **قواعد الحضور والانصراف والخصومات:**
  - وقت بدء ونهاية الدوام، فترة السماح (Grace Period)، حد نصف اليوم، وموعد تسجيل الغياب الآلي.
  - تفعيل أو تعطيل الخصومات التقديرية.
  - تحديد قيمة الخصم بالدقيقة أو مبالغ الغياب ونصف اليوم والانصراف المبكر.
  - كشف ومراقبة عناوين الـ IP المشبوهة لمنع التلاعب.
- **إدارة الموظفين والأقسام وجداول الدوام:**
  - إضافة، تعديل، تعطيل، وحذف الموظفين.
  - إنشاء الأقسام وجداول الدوام المختلفة وتعيينها للموظفين.
  - تقويم العطلات الرسمية.
- **سجل العمليات والرقابة (Audit Trail):**
  - تسجيل دقيق لكافة الإجراءات الإدارية وتغييرات الإعدادات وتعديلات السجلات.

### 3. التصميم وتجربة المستخدم (UI/UX)

- زر تبديل فوري بين **العربية والانجليزية (AR / EN)**.

## 🛠️ البنية التقنية (Tech Stack)

- **Backend:** Node.js (v24 LTS) + Express 5
- **Database:** SQLite المدمجة فائقة السرعة (`node:sqlite DatabaseSync`) مع نمط WAL والعلاقات المترابطة
- **Authentication:** JSON Web Tokens (JWT) + Bcrypt Password Hashing
- **Frontend:** Single Page Application (HTML5, Tailwind CSS, JavaScript Vanilla ES6+, Lucide Icons)
- **Maps:** Leaflet.js & OpenStreetMap
- **Camera & Geolocation:** HTML5 WebRTC MediaDevices API & Geolocation API
- **Exporting:** UTF-8 BOM CSV / Excel Exporter
